# andOTP for Android (legacy)

This directory holds the original Java/Gradle Android app, version 0.9.0.1, which is
**unmaintained**. It is kept for reference and for its translations, thumbnails and store metadata.

The Rust rewrite in the repository root replaces it. Both implementations use the same backup format,
so you can move accounts between them.

To build the old app, run `./gradlew assembleDebug` from this directory (requires the Android SDK, API 30).
